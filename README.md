# Venus Maximus

A looking-room.

What you notice matters. What you choose matters. This place remembers.

This is a game before it is a token. There is no wallet in the first chamber. There is no ticker. Crypto has to earn its way in later.

## Play

1. Look.
2. Tap the pale marks to stand.
3. Drag to look. Finger down looks up.
4. Hold a gold thread to attend.
5. At the well, look up.
6. Keep, or give to the well.

The room remembers.

## What this is

The first chamber of Venus. One object: Dawn Interval. A gap, not a crystal. Two malachite lips. Gold only where they almost meet.

Keep and it comes with you. Give and it is gone. A second voice. A seam of light you cannot walk through.

Mute still plays by light.

## What this is not

Not an airdrop treadmill. Not an idle clicker. Not a token with a game taped on.

$VENUS exists on XRPL and Ethereum. It is not in this build. The game must be worth playing if the ticker vanished tomorrow.
